# Historical PyQt5 RC1 records

pyqt5-rc1 contains the original main-branch documents, build configuration and binary inventories copied before the v0.2.0-dev source update. Those files are preserved as historical text records. Their relative links and instructions refer to their original repository layout and may point outside the archive. Use the current root README and DISTRIBUTION for this branch. Original screenshots remain in docs/screenshots and depict the older iteration.
